# Security Lab Notes

本仓库记录本地隔离靶场的安全实验、检测规则和漏洞研究笔记。

## 范围

- 漏洞情报：CISA KEV、NVD、EPSS 的归一化与排序；
- 靶场：VirtualBox 隔离虚拟机、DVWA/Juice Shop、断网与快照回滚；
- 渗透测试：只针对本地靶场的侦察与复现；
- 防守：Sigma 检测规则与等价验证脚本；
- 报告：每次实验一份，模板在 `docs/reports/_模板.md`。

## 不包含

- 恶意样本、虚拟机磁盘、凭证、token、内网地址；
- 任何针对第三方系统的扫描或攻击记录。
