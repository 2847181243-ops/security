# 检测流水线（当前实现）

## 数据流

原始访问日志
→ normalize_web_log.mjs（拆 c_ip/method/uri/cs_uri_stem/cs_uri_query/status）
→ normalize_and_detect.mjs（最多两层 URL 解码 + HTML 实体解码）
→ 规则匹配（SQLi/XSS/LFI/SSRF/Spring/Struts/Tomcat PUT）
→ 告警/证据落盘

## 规则与字段

| 规则 | 字段 | 解码后匹配 |
|---|---|---|
| SQLi | cs_uri_query | 是 |
| XSS | cs_uri_query | 是 |
| LFI | cs_uri_query | 是 |
| SSRF | cs_uri_query 的 url= | 是 |
| Spring4Shell | cs_uri_query | 否 |
| Struts OGNL | cs_uri_query | 否 |
| Tomcat PUT | method + cs_uri_stem | 否 |

## 已知缺口

- POST body / header 不进入当前日志；

- Sigma 引擎未执行，等价脚本只覆盖逻辑；
