# 漏洞发现演练方法论（本地/授权）

## 1. 选目标

- 小而完整：有输入入口、有状态、有权限边界；
- 优先自己能读源码、能本地跑的目标。

## 2. 枚举输入

- URL/query/body/header/cookie、文件上传、CLI/API；
- 标出未认证可达的入口。

## 3. 审数据流

- 输入 → 解析 → 拼接/查表/写文件/发请求；
- 重点：路径、命令、模板、反序列化、鉴权判断。

## 4. 候选与 PoC

- 每个候选写清前置、影响、最小请求；
- 只做固定回显/固定命令，不做后门。

## 5. 分诊

- 设计内漏洞 vs 新问题；
- 可利用性、权限要求、影响范围；
- 未验证的标“候选”，不写成结论。

## 6. 修复与回归

- 修在源头（转义、白名单、上限、containment）；
- 加回归脚本，防回退。

## 7. 披露演练

- 按 docs/security/披露模板.md 写 advisory；
- 自建代码不申请 CVE；第三方先找 security.txt/仓库渠道。
