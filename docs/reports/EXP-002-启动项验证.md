## 1. 目标

验证 HKCU Run 启动项的添加、查询、删除与残留检查。

## 2. 范围与环境

- lab-win，baseline-win11，Internal Network labnet；
- 只改注册表，不执行文件。

## 3. 假设

H1：写入后 reg query 能看到完整路径；删除后查不到。

## 4. 步骤

1. reg add HKCU\...\Run /v FakeUpdater /d C:\lab\fake-updater.cmd；
2. reg query 该值；
3. reg delete 该值；
4. 再查。

## 5. 结果

| 检查项 | 预期 | 实际 | 结论 |
|---|---|---|---|
| 添加 | 成功 | The operation completed successfully | 通过 |

| 删除 | 成功 | 成功 | 通过 |
| 再查 | 找不到 | 系统找不到指定注册表项 | 通过 |

## 7. 分析

Run 键可作为排查入口；测试条目已删，无残留。

## 8. 风险与影响

真实恶意软件常用同类键做持久化；排查要覆盖 HKCU/HKLM 两处。
