# 实验报告目录

每次实验（EXP-xxx、靶场部署、样本分析）完成后，必须在这里留一份报告。

- 模板：`_模板.md`（结构参考 OWASP WSTG 报告章节与公开渗透测试模板，改写为实验场景）。
- 命名：`<编号>-<短标题>.md`，例如 `EXP-001-EICAR检测.md`。
- 证据：命令输出、文件路径、截图、哈希；推断标“推断”。
- 未完成的实验写“部分完成”，不能写成通过。
- 报告索引：`索引.md`。

参考：
- OWASP WSTG Reporting Structure：https://wstg.owasp.org/latest/5-Reporting/01-Reporting_Structure/
- 公开模板（External Network Penetration Test — Report Template）：https://github.com/mukul975/anthropic-cybersecurity-skills/blob/main/skills/performing-external-network-penetration-test/assets/template.md
